ZWEI ERKENNTNISSE VORWEG (aendern den Plan)
------------------------------------------------------------------------

- Beide Automatisierungen (Termine + Sets) brauchen einen kleinen
  Server-Teil. Direkt aus dem Browser scheitert es an CORS. Auf einem
  eigenen Server ist das trivial (kleines Script + Cron), bei GitHub
  Pages braeuchte es einen Umweg.
  => Termin- und Set-Automatik erst beim Eigenhosting richtig bauen.

- Die SoundCloud-API ist seit Jahren fuer Neuanmeldungen geschlossen.
  Ein offizieller Key ist praktisch nicht zu bekommen.
  Machbar bleibt: oeffentlicher RSS-Feed des Profils (serverseitig
  abgerufen) oder das SoundCloud-Embed-Widget. Titel stimmen dann
  automatisch ueberein.
